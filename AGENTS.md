# TextizoFX look kit

This folder lets an AI agent make looks for **TextizoFX**, an animated text plugin (OpenFX) for DaVinci Resolve's Edit and Fusion pages. A look is one TextizoFX node in a small `.setting` file.

When the user asks for a TextizoFX look, an animated title, a text animation or changes to one, **read `SKILL.md` and follow it**. It points you to `TextizoFX AI Guide.md`, the full reference.

Ground rules:

- Ask the user where to save looks before writing anywhere outside this folder.
- Put new work in `my-looks/`. Leave the kit files unchanged unless the user asks: `presets/`, `specs/`, `reference/`, `tools/`, the guide, `SKILL.md`.
- Do not delete or overwrite the user's files without asking.
